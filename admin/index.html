Publicar GitHub e Redes (opcional)

Fica só na memória desta aba — nunca é salvo em disco nem enviado a nada além da API do GitHub. Use um token com escopo restrito a este repositório (fine-grained personal access token, permissão "Contents: Read and write"). Preencher aqui também permite que o código do imóvel (em Dados básicos) busque o próximo número sozinho. Depois de publicar, o próprio GitHub Actions cuida de postar automaticamente no Instagram/Facebook (token já configurado nos Secrets do repositório) — não precisa colar nenhum token de rede social aqui.
